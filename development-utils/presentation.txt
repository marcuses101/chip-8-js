History
# Originally developed for 1970 era 8 bit microcomputers
# COSMAC VIP, Telmac 1800
# Resurfaced in the 1990s on the HP48 calculator
# Now considered the "Hello World" of emulation
---
VM Specs
# 4K memory (0x000-0xFFF)
# 16 8-bit registers (V0-VF)
# 12-bit I register
# 12-bit program counter
# 60Hz sound timer and delay timer
# Hexadecimal keypad (0-F)
# 64*32 pixel monochrome display (256 byte framebuffer)
# Drawing sprites with XOR and collision detection
